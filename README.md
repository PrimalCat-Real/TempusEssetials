# Template Plugin

Plugin made for TEMPUS VANILLA

Modules Overview
Tab Addon (tab-addon: true)
Rapid Leaf Decay (rapid-leaf-decay: true)
Drop Chances (drop-chances: true)
Configures custom drop rates for various mobs:
EVOKER: 0.5% chance to drop Totem of Undying or Emerald.
ZOMBIFIED PIGLIN: 5% chance to drop Gold Nugget.
VINDICATOR: 0.5% chance to drop Emerald.
PILLAGER: 0.5% chance to drop Emerald.
WITCH: 1% chance to drop Glowstone Dust, Redstone Dust, or Gunpowder; 0.5% chance to drop Emerald.
WITHER SKELETON: 0.5% chance to drop Wither Skeleton Skull.
Custom Signs (custom-sign: true)
Kill Empty Boats (kill-empty-boats: true)
Copybook (copybook: true)
Stop Items on Death (stop-items-on-death: true)
Bosses Mute (bosses-mute: true)
Villager Trade Modifier (villager-trade-modifier: true)
Modifies villager trades for different professions:
Armorer: Trades gold armor instead of diamond armor.
Weaponsmith: Trades gold sword instead of diamond sword.
Toolsmith: Trades gold tools instead of diamond tools.
Librarian: Offers custom enchanted books (e.g., Mending for Smite V).
Playtime Rewards (playtime-rewards: true)
Role-Play Nicknames (rp-nicks: true)
Right-Click Farmland Protection (right-click-farmland: true)
Stronger Dragon (stronger-dragon: true)
Enhances the Ender Dragon boss fight, making it more challenging.
